# To-Do List — Frontend

Aplicação **React + Vite** que consome a API To-Do List, permitindo gerenciar tarefas com autenticação e interface responsiva.

---

## 📝 Sobre

Este projeto é a interface do usuário do sistema **To-Do List**, desenvolvido com **React**, **TypeScript** e **Vite**.  
Permite login, visualização, criação, edição e exclusão de tarefas, comunicando-se com a API via **Axios**.

---

## 📌 Funcionalidades

- Login com integração à API.
- CRUD de tarefas (criar, listar, editar e excluir).
- Interface responsiva com **TailwindCSS**.
- Validação de formulários com **React Hook Form** e **Zod**.

---

## 🚀 Tecnologias Utilizadas

- **React** — Biblioteca para construção da interface.
- **Vite** — Ferramenta de build rápida.
- **TypeScript** — Tipagem estática para JavaScript.
- **Axios** — Cliente HTTP para comunicação com API.
- **Matirial-UI** — Estilização rápida e responsiva.
- **React Hook Form** — Manipulação de formulários.
- **Zod** — Validação de dados.

---

## 🛠 Instalação e Execução

1. **Clone o repositório**
```bash
git clone https://github.com/Marcos-Samuel/to-do-list-front.git
````
Acesse a pasta do projeto

```bash
cd to-do-list-front
```
Instale as dependências
```bash
npm install
```
Inicie o servidor de desenvolvimento
```bash
npm run dev
```
O frontend estará disponível em:
```bash
http://localhost:5173
```

